# Asan Pakistan — Frontend Portfolio Project

A responsive React + Vite concept website for a Pakistani cab-booking service.

## Features
- Responsive landing page
- Pickup and destination inputs
- Demo fare calculator and vehicle selection
- Booking preview interaction
- Login and signup modal UI
- Clear labels explaining that this is a frontend-only portfolio demo

## Run locally
1. Install Node.js (LTS).
2. Extract this project and open its folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Production build
Run `npm run build`.

## Current limitations
This is a frontend-only demo. Login/signup does not create accounts, bookings are not stored, and maps, live driver tracking, real distance calculations, and payments are not connected. The displayed fares are illustrative estimates.
